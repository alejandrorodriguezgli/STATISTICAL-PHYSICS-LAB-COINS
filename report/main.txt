\section{Enumeration of Microstates}

\subsection{Enumeration of All Microstates for $N=7$}

A microstates describes one particular configuration of the N coins, taking into account that each coin has 2 possibilities, Heads (H) and Tails (T) the total number of possible microstates for a system  of N coins is:

\begin{equation}
    \Omega_{\mathrm{total}} = 2^N .
\end{equation}

For the case of $N=7$, each microstate is a string of seven letters, H or T. And the total number of microstates is therefore:
\[
    \Omega_{\text{total}} = 2^7 = 128.
\]



The microstates are grouped according to the number of heads,$k$. The number of configurations containing exactly
$k$ heads is given by the binomial coefficient

\begin{equation}
    \Omega(7,k) = \binom{7}{k}
    = \frac{7!}{k!(7-k)!}.
\end{equation}

\begin{equation}
\sum_{k=0}^{7}\binom{7}{k}

\end{equation}

This confirms that all possible microstates have been enumerated
exactly once, so the code is correct.
It is important that the distribution is symmetric so the number of configurations with $k$ heads is equal to the number
with $7-k$ heads.

\subsection{Computational Limits of Microstate Enumeration}

The target of this part is to determine the largest number
of coins for which all possible microstates can be generated and stored in less than five minutes.

The total number of microstates increases exponentially with
the number of coins:

\begin{equation}
    \Omega_{\mathrm{total}}(N)=2^N.
\end{equation}


\subsubsection*{Methodology}

For each value of $N$, the program generates all possible binary
configurations and stores them in a Python list. 
To evaluate the performance of the program it was used the function \texttt{time.perf\_counter()} to measure execution time , while memory consumption was monitored using the \texttt{tracemalloc}.

\subsection{Distribution of Microstates}

The number of microstates with $k$ heads is the binomial coefficient:

\[
\Omega(N,k)=\binom{N}{k}=\frac{N!}{k!\,(N-k)!}
\]

To compute it, we cancelled the $(N-k)!$ and used the product
$\Omega(N,k)=\prod_{i=1}^{k}\frac{N+1-i}{i}$, which avoids calculating
very large factorials.
For large $N$ we used $\ln\Omega$, computed with the log-gamma function.

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.7\linewidth]{figures/omega_distributions.pdf}
  \caption{$\Omega(N,k)$ for $N=20, 50, 80, 100$ (logarithmic scale).}
\end{figure}

All curves have their maximum at $k=N/2$ and are equal to 1 at $k=0$ and
$k=N$. The maximum grows very fast: about $10^5$ for $N=20$ and $10^{29}$ for
$N=100$.


\subsection{Maximum N}

\begin{itemize}
    \item Exact calculation: no limit, but it gets slower
    ($0.073 \pm 0.005$ s for $N=1000$, $3.24 \pm 0.04$ s for $N=4000$).

    \item Plotting: the largest number a computer float can store is about
    $1.8\times10^{308}$, so the maximum $N$ we can plot is $N=1029$.
\end{itemize}

Using $\ln\Omega$ instead removes this limit.


\subsection{Limit $N \sim 10^{23}$}

For large $N$ the distribution becomes a Gaussian with width
$\sigma=\sqrt{N}/2$, so the relative width is:

\[
\frac{\sigma}{N/2}=\frac{1}{\sqrt{N}}
\]

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.7\linewidth]{figures/probability_narrowing.pdf}
  \caption{Probability versus fraction of heads $k/N$. The peak gets narrower
  as $N$ grows.}
\end{figure}

For $N=10^{23}$ the relative width is about $3\times10^{-12}$, so the
distribution is a very sharp peak at $k=N/2$. This means a macroscopic system
is practically always in the most disordered state.

\subsection{Parameter Assignment}

Considering a system of $N=100+M$ unbiased coins where $M$ is the harmonic mean of the last two digits of the team members' NIAs (46, 13, 28 and 06).

\[
M=\frac{4}{\frac{1}{46}+\frac{1}{13}+\frac{1}{28}+\frac{1}{6}}
\approx 13.2871
\]

Therefore, $N \approx 113.2871$, and since the number of coins must be an integer, we choose $N=114$, the nearest even integer, so that $N/2=57$. 


\subsection{Probability Calculations}

The probability of obtaining $k$ heads is calculated using:

\[
P_k=\frac{\Omega(N,k)}{2^N}
=\frac{N!}{k!(N-k)!2^N}
\]

For $N=114$, the results are:

\begin{itemize}
    \item[(a)] 30 heads:
    $P(30)=1.3931\times10^{-7}$

    \item[(b)] 57 heads:
    $P(57)=0.074565$

    \item[(c)] Between 47 and 67 heads:
    $P=0.951275$

    \item[(d)] Between 37 and 77 tails:
    $P=0.999896$
\end{itemize}

For (c) and (d), we sum the probabilities over the corresponding intervals. The results show that macrostates near $N/2$ are much more probable than those far from the center.


\subsection{Entropy Changes}

Using Boltzmann's equation,

\[
S=k_B\ln\Omega
\]

the entropy difference between two macrostates is:

\[
\Delta S=S(k_1)-S(k_2)
=k_B\ln\left(\frac{\Omega_1}{\Omega_2}\right)
\]

where $k_B=1.380649\times10^{-23}$ J/K.

The calculated entropy changes are:

\begin{itemize}
    \item[(e)] 82 and 57 heads:
    $\Delta S=-1.5519\times10^{-22}$ J/K

    \item[(f)] 67 and 57 heads:
    $\Delta S=-2.4133\times10^{-23}$ J/K

    \item[(g)] 57 and 20 heads:
    $\Delta S=+3.5628\times10^{-22}$ J/K
\end{itemize}

Entropy is maximum at $k=N/2$, where the number of microstates is largest. In (e) and (f), the entropy difference is negative because the first state has lower entropy. In (g), it is positive because the first state has higher entropy.
